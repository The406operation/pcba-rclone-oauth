PCBA rclone — My rclone app

PCBA rclone is the owner's private use of rclone to transfer PCBA files between their Mac, Windows PC and Google Drive. It is not offered to other users as a public service. Its Google OAuth application is named "My rclone app" in the "PCBA rclone" project.

Google authorization lets the local rclone client access the account selected during consent. Rclone uses that access for the file operations the owner chooses. The permission granted by Google and the selected command determine what the client can do.

This website provides documentation only. It does not provide sign-in, receive files or OAuth credentials, or run synchronization jobs.
