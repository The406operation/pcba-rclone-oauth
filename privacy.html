PCBA rclone privacy policy

Effective when published.

Purpose and data accessed

PCBA rclone is a private application for the owner's Mac and Windows PC. Its purpose is transferring the owner's PCBA files between those computers and Google Drive using rclone. Depending on the access authorized and the operation selected, rclone can access file and folder metadata and file contents. It may create, update or delete files when the granted permission and selected command allow that operation. Access and refresh tokens authenticate the client and allow it to renew access.

Use and separate workflows

This OAuth application is used to authorize the owner's rclone transfer and file-management workflow. The owner also uses ChatGPT and Codex with PCBA materials, sometimes through connected Google Drive. Those are separately authorized workflows governed by the services' terms, privacy policies and account settings. This policy does not claim that PCBA documents are never processed by AI services. It does not authorize an additional destination or processing purpose for the rclone workflow.

Storage, logs and retention

Files are stored in the selected local locations and Google Drive. OAuth credentials are retained in the local rclone configuration so that the client can renew access. They are not included in this documentation website or its public source repository.

Rclone operations can produce console output and, where configured, persistent logs or caches. Records may contain file names, paths, transfer status or errors. Their locations and retention depend on the commands, configuration and backups used on each computer. The owner manages these records and local copies; no fixed deletion interval or absence of local logging is asserted. Google's service-side processing and logs are governed by Google's policies. Revoking access does not erase local files, logs, caches, backups or Drive copies.

Control and changes

The owner can stop rclone jobs and remove this application's authorization in the Google Account's connected-app settings. Local credentials and files must be removed separately when no longer needed. This policy must be reviewed before using this OAuth application with additional transfer destinations, custom telemetry, shared logging, server components or other processing purposes.

Documentation website

The site consists of static pages without site-added forms, analytics scripts or tracking cookies. GitHub Pages serves the pages and may collect visitor and request information, including IP addresses, under GitHub's privacy statement. The website itself receives no Google Drive files or OAuth credentials.

Contact

Questions about this application and its privacy practices can be sent to pcba-rclone-support@googlegroups.com.

Support inquiries are processed by Google Groups and delivered to the owner's Gmail inbox. Inquiries may include the sender's email address and message content and are retained in a private group archive and the owner's mailbox. The owner manages retention; no fixed deletion interval is promised. Please do not send passwords, OAuth tokens, client secrets or project files.
